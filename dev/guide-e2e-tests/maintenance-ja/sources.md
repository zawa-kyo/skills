# 参照元

## 主な参照文献

Vladimir Khorikov, _Unit Testing: Principles, Practices, and Patterns_。

主に参照した箇所は次のとおり。

- 第2章: 利用者視点から広い範囲を通す結合テストとしての E2E テスト
- 第4章: 高いリグレッション検出力、リファクタリング耐性、フィードバックコスト、テストピラミッド上の位置付け
- 第8章: デプロイ済みエントリーポイント、含める依存関係、最長の正常系、デプロイ後の基本動作確認

## 採用した考え方

- E2E テストは、外部クライアントの視点からシステムの広い範囲を通して確認する。
- 重要で代表的な一連の振る舞いへ絞る。
- 広いリグレッション検出力を得られ、遅いフィードバックと高い保守コストを許容できる場合に使う。
- 実際のクライアントを表す場合は、管理下の状態もアプリケーションを通じて確認する。

## このスキルでの調整

参照文献だけでは、テスト環境を安定して運用するための詳細が不足している。
そのため、特定フレームワークに依存しない保守的な指針を追加する。

- 特定のデプロイ方法を必須にせず、プロジェクトの E2E テストの境界を確認して尊重する
- 環境上の前提と対象外の依存関係を明示する
- テストで使う状態をほかのテストから分離する
- 上限時間を設け、観測可能な条件を待つ
- 原因調査に必要な情報を残す
- 継続的に不安定なテストを欠陥として扱う

これらはワークフロー上の調整であり、参照文献が特定のブラウザ技法や分散テスト技法を扱っているという主張ではない。
