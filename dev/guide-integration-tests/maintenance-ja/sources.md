# 参照元

## 主な参照文献

Vladimir Khorikov, _Unit Testing: Principles, Practices, and Patterns_。

主に参照した箇所は次のとおり。

- 第8章: 結合テストの責務、管理下と管理外の依存関係、シナリオの選択
- 第9章: システム境界での相互作用検証、自分たちが所有するアダプタ
- 第10章: 本番に忠実なデータベース、テストデータのライフサイクル、準備処理の再利用

## 採用した考え方

- 結合テストでは、狭いテストで証明できない実際の連携を確認する。
- 依存関係の実際の振る舞いが対象に含まれ、その影響を閉じ込められる場合は、本番に忠実な実体を使う。
- 外部から観測できる通信は、自分たちが所有するシステム境界で検証する。
- テストで使う状態をほかのテストから独立させ、後始末のために本番の振る舞いを変えない。

## 調整した考え方

- 「モックは結合テストでだけ使う」という主張は、普遍的なルールにはしない。
  単体テストでも、通信自体が振る舞いである場合はテストダブルを使えるようにする。結合テストでは、意味のある境界で通信を確認する。
- 管理下の依存関係と管理外の依存関係は、状況に応じて使える用語であり、必須の分類にはしない。
- 実物の依存関係を利用できない場合は、すべての結合テストを否定せず、保証できない範囲として記録する。
- コンテナ、並列実行、後始末の方法は、一律に決めず、プロジェクトのコストと本番への忠実度から選ぶ。
